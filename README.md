# Simple-Borderlands-Online-Zoom
A simple zoom and coordinate display for Borderlands Online

# How To Install
1. In order to use this mod you must load it with melon loader 7.0.
2. You can get melon loader here - https://github.com/lavagang/melonloader
3. Install using the exe or your preferred method and when selecting a version to use with borderlands online select 7.0, later versions can break functionality.
5. Run borderlands online to create a mods folder in the same location as your BOL.exe.
6. Download and extract the .zip file from your chosen release.
7. Add BorderlandsZoom.dll to your new mods folder, and enjoy.

# Controls
Thank you for using Simple Borderlands Zoom, the controls are as follows

- Coordinate Menu
  - F1 - to toggle the menu
  - Shift + F1 - to swap between two menu sizes

- Zoom
  - C - to zoom in by 50 fov
  - C + Scroll Wheel - to further zoom in or out
